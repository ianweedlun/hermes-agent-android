# Hermes Mobile — IPC & Protocol Contract

## Purpose
Defines the strict communication boundary between Native Android (Kotlin), the WebView frontend (JavaScript), and the Hermes agent daemon (Python in PRoot).

---

## 1. Transport Mechanisms
- **Native Kotlin ↔ Hermes Daemon (PRoot):**
  - Local loopback HTTP server (`127.0.0.1:<port>`) with a high-entropy bearer token generated by Kotlin at startup and injected into PRoot via environment variable `HERMES_IPC_TOKEN`.
  - Unix domain socket (`/data/user/0/ai.hermes.mobile/files/ipc.sock`) for low-latency streaming of terminal PTY bytes to the native bottom sheet.
- **Native Kotlin ↔ WebView PWA:**
  - Bidirectional communication via Android `@JavascriptInterface` bridge (`HermesNativeBridge`) and evaluating JavaScript callbacks via `WebView.evaluateJavascript()`.

---

## 2. Event Payload Schemas (JSON-RPC 2.0)

### A. Daemon Status Event (`daemon/status`)
Emitted by the daemon to update native UI state and notification badges:
```json
{
  "jsonrpc": "2.0",
  "method": "daemon/status",
  "params": {
    "state": "idle" | "thinking" | "executing_tool" | "error",
    "active_tool": "string or null",
    "step_index": 42,
    "session_id": "uuid"
  }
}
```

### B. Telemetry Heartbeat Event (`daemon/telemetry`)
Sent every 30 seconds while active:
```json
{
  "jsonrpc": "2.0",
  "method": "daemon/telemetry",
  "params": {
    "uptime_seconds": 3600,
    "rss_bytes": 157286400,
    "cpu_percent": 3.5,
    "active_model": "gemini-3.8-flash"
  }
}
```

### C. Native Notification Trigger (`native/notify`)
Requests Android SystemUI notification from the agent:
```json
{
  "jsonrpc": "2.0",
  "method": "native/notify",
  "params": {
    "title": "Task Complete",
    "body": "Scaffolding build succeeded",
    "priority": "default" | "high",
    "action_intent": "open_chat" | "open_terminal"
  }
}
```

---

## 3. Guarantees & Constraints
1. **Zero External Access:** The daemon loopback endpoint never binds to `0.0.0.0` or any external network interface.
2. **Authentication Required:** Any request without the valid `HERMES_IPC_TOKEN` header is rejected with HTTP 403.
3. **Backpressure:** The PTY socket stream buffers up to 64KB; excessive drops notify the UI with an overflow indicator.
