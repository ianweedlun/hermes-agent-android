# Hermes Agent Mobile (.hermes.md)

## Mission & Primary Directive
Build a **fully self-contained, native Android Hermes Agent experience** in a single APK (`ai.hermes.mobile`).

### Zero-Worthless-Testing Gate (CRITICAL RULE)
- **Do NOT ask the user to install or manually test intermediate plumbing builds or mock stubs.**
- All validation must run headlessly in the MacBook Air emulator lab via `scripts/run-device-tests.sh`.
- The user only touches an APK after the automated lab verifies an end-to-end run: rootfs extracts, `hermes-agent` daemon boots, the authentic WebUI renders, and a test prompt completes.

---

## Architectural Plan of Record

1. **Pre-baked Linux Runtime (PRoot + Alpine aarch64):**
   - Do NOT use hollow stubs or mock in-memory HTTP servers (e.g. `LocalAgentServer.kt` serving dummy HTML).
   - The Alpine rootfs (`hermes-rootfs-aarch64.tar.gz`) must come pre-baked with Python 3, `uv`, dependencies, and `hermes-agent` pre-installed for instant, offline-capable first boot.
   - Managed via PRoot with fake root (`-0`), mounting `/workspace`, `/state`, and `/tmp` per `STORAGE-CONTRACT.md`.

2. **Real Daemon Execution:**
   - `DaemonSupervisor.kt` boots the real `hermes-agent serve` process bound strictly to `127.0.0.1:8787`.
   - Supervised inside `HermesDaemonService.kt` as an Android foreground service (`specialUse`).

3. **Interface & Interaction:**
   - **Primary Viewport:** Full-screen WebView directly loads the local Hermes WebUI at `http://127.0.0.1:8787` with token authentication.
   - **Terminal Sheet:** Native Material 3 sliding bottom-sheet connected directly to the PTY file descriptor of the PRoot shell session for full interactive CLI control.
   - **Native Hardware Bridge:** `window.HermesHardware` exposes platform APIs (battery, network, haptics, clipboard) directly from Kotlin per `HARDWARE-BRIDGE-CONTRACT.md`.

4. **First-Run Setup & Inference:**
   - On initial launch, present a quick-preset setup dialog for Cloud API keys (Antigravity, OpenRouter, Gemini).
   - Support LAN / Tailscale mesh endpoints (e.g. 10.0.2.13:8080) and local GGUF fallback per `MODEL-FALLBACK-CONTRACT.md`.
